ASSIGNED 3 VALIDATION & BUSINESS ERRORS:
--------------------------------------------------------------------------------
1. Error Code: ERR_DISP_ORDER_REQUIRED
   Name:      Missing Order Reference for Dispatch
   Condition: Dispatch job creation attempted without linking to a valid Order ID.
   Message:   "ERR_DISP_ORDER_REQUIRED: Order ID is required for courier dispatch."

2. Error Code: ERR_RET_ORDER_REQUIRED
   Name:      Unlinked Return Ticket Submission
   Condition: Return claim ticket submitted without a verifiable Order ID.
   Message:   "ERR_RET_ORDER_REQUIRED: Order ID is required for return ticket."

3. Error Code: ERR_RET_REASON_REQUIRED
   Name:      Unclassified Warranty/Return Claim
   Condition: Return submission attempted without selecting a recognized defect reason category.
   Message:   "ERR_RET_REASON_REQUIRED: Please select a return or warranty reason."
